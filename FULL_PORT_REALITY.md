# What a “full port of every line” actually means

**Repo:** official OrcaSlicer source (`S117X/IOS-port-OrcaSlicer`, branch `ios-port`).  
**We are not inventing a second slicer.**

## Correct complete port

```
Official libslic3r (every algorithm line stays C++)
        ↑
   orca_ios_api C wrapper
        ↑
   SwiftUI (new shell only — required because wxWidgets ≠ iOS)
```

## How to verify engine today

```bash
# Real slice (official engine on Mac)
./build-macos-headless-arm64/src/ios/orca_slice_cli.app/Contents/MacOS/orca_slice_cli \
  ios/sample_cube_20mm.stl /tmp/out.gcode

# Mac host with linked engine (My Mac destination)
open ios/OrcaSlicer.xcodeproj
# Load sample cube → Slice with libslic3r

# iOS Simulator UI
xcodebuild -project ios/OrcaSlicer.xcodeproj -scheme OrcaSlicer \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' build
```
